# North Star Bakery Website

This repository contains the HTML and CSS files for the North Star Bakery client website. 

## Project Details
* **Student:** Justin Daniels
* **Course:** Introduction to Web Development
* **Assignment:** Touchstone 3 - Visual Design and Responsive Layout

## Overview
This project demonstrates a multi-page website built with a mobile-first approach. It includes:
* Semantic HTML5 structure
* A cohesive visual design system with a custom color palette and typography
* Responsive layout utilizing CSS Flexbox and media queries
* Accessible forms, images with alt text, and multimedia elements with fallback descriptions
